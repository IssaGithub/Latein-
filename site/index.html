Motivation + Struktur + LRS-Fokus

Latein Sprint App

Vom Frust zum Erfolg: kurze Daily Sprints, intelligente Korrektur und ein Datenmodell, das Stamm und Endung sauber trennt.

LRS-Filter testen

User Flow (5 Minuten)

  1. Phase A - Erkennen: Audio + Wort, Antwort per Bild oder Bedeutung.
  2. Phase B - Struktur: Wortstamm + Endungen, richtige Endung antippen.
  3. Phase C - Produktion: Wort aktiv schreiben, anschliessend LRS-freundliche Auswertung.

Datenmodell (Kern)

  • vocabulary: lemma, word_stem, word_type, audio
  • grammar_suffixes: suffix, function_label, color
  • vocabulary_form: Verknuepfung von Stamm + Endung
  • user_progress: last_seen, stability, last_error_type
  • image_upload + generated_task

Bild-Upload zu Aufgaben

Upload -> OCR/Extraktion -> Aufgaben-Generator -> Freigabe -> Sprint-Aufgaben.

So lassen sich Buchseiten oder Arbeitsblaetter direkt in uebbare Aufgaben umwandeln.
